📖 操作说明

🖱 鼠标操作

  • 收集阳光：点击阳光图标收集阳光值
  • 选择植物：点击上方植物卡牌选中
  • 放置植物：选中后点击草坪格子种植
  • 取消选择：点击卡牌右侧空白区域或按 ESC
  • 铲除植物：点击右侧铲子按钮（或按 Q 键），再点击植物

⌨ 键盘快捷键

  • 1-9：选择对应植物卡牌
  • ESC：取消植物选择 / 取消铲子模式 / 关闭弹窗
  • 空格：暂停 / 继续游戏
  • P：暂停 / 继续游戏
  • Q：切换铲子模式
  • Enter / 空格：开始关卡 / 进入下一关

📱 触屏操作

  • 点击阳光收集
  • 点击卡牌选择植物
  • 点击草坪格子种植
  • 点击铲子按钮铲除植物

💾 存档机制

游戏自动使用浏览器 localStorage 保存关卡进度。通关后自动解锁下一关，刷新页面后进度保留。

🔊 音效

使用 Web Audio API 生成合成音效，点击右上角喇叭按钮可随时静音/恢复。

⚠ 重置存档

此操作会删除本游戏的关卡进度和设置，且无法恢复。
