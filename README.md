# 植物大战僵尸 — 浏览器版

基于 HTML5 Canvas 的植物大战僵尸复刻，纯前端实现，双击即玩。

## 运行

双击 `index.html`，浏览器直接打开即可。

## 玩法

- 5×9 网格战场
- 9 种植物：向日葵、豌豆射手、坚果墙、寒冰射手、樱桃炸弹、双发射手、土豆地雷、大嘴花、加特林豌豆
- 僵尸带行走/攻击/死亡动画
- 阳光经济 + 卡牌选择
- 割草机防线

## 操作

| 操作 | 说明 |
|------|------|
| 点击卡牌 | 选择植物 |
| 点击格子 | 种植 |
| 点击阳光 | 收集 |
